시트 내보내기 버튼 (GM용)

Roll20 게임 화면에서 이 버튼을 누르면 PC 시트를 읽어서 저널(GitHub)에 저장해요. 레벨이 바뀐 PC는 바뀌기 전 시트를 레벨 기록으로 따로 남겨요. 판델버와 드래곤 하이스트 둘 다 같은 버튼 하나로 돼요.

확장 프로그램을 쓰면

Roll20 저널 도우미(0.7.6 이상)를 쓰는 GM 브라우저라면 북마크는 필요 없어요. 게임 화면이 레벨이 바뀐 PC를 알아서 알려 주고, 알림의 시트 내보내기나 GM 패널의 시트 → 저널 내보내기로 저장돼요. 토큰은 확장 아이콘을 눌러 나오는 설정 창의 PC 시트 → 저널 칸에 넣어요. 토큰 만드는 법은 아래 2번과 같아요.

1. 버튼 설치 (확장 없이 쓸 때)

아래 버튼을 브라우저 북마크바로 끌어다 놓으세요. (북마크바가 안 보이면 Ctrl+Shift+B)

시트 내보내기

2. GitHub 토큰 만들기 (처음 한 번)

  1. GitHub 토큰 만들기를 열어요.
  2. 이름은 아무거나, 만료 기간은 원하는 만큼.
  3. Repository access에서 Only select repositories → Phandelverdelver, Dragonheisthesit 두 개 선택.
  4. Permissions → Repository permissions → Contents를 Read and write로.
  5. 만들어진 토큰을 복사해 두세요. 채팅이나 다른 곳에는 붙여 넣지 마세요.

3. 쓰는 법

  1. Roll20 게임에 GM으로 들어가서 북마크바의 시트 내보내기를 눌러요.
  2. 처음엔 창에 토큰을 붙여 넣어요. 그 브라우저에만 저장되고 다음부터는 안 물어봐요.
  3. 확인만: 저장하지 않고 레벨 변화만 보여 줘요. 내보내고 저장: GitHub에 저장해요.
  4. 1~2분 뒤 저널의 캐릭터 시트에 반영돼요. 레벨 기록은 시트 위쪽 레벨 기록 목록에서 골라 볼 수 있어요.

레벨업할 때마다 눌러 주면 돼요. 레벨이 그대로면 기록은 새로 안 생기고 현재 시트만 갱신돼요. 내보내는 동안 시트 창이 잠깐씩 열렸다 닫혀요.
