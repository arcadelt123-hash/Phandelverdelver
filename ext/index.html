Roll20 저널 도우미 설치 (GM용)

GM 브라우저에만 까는 확장 프로그램이에요. 플레이어는 깔지 않아요.

확장 내려받기 (0.8.2)

설치

  1. 내려받은 zip을 압축 풀어요 (폴더 하나).
  2. 크롬 주소창에 chrome://extensions를 열고, 오른쪽 위 개발자 모드를 켜요.
  3. 압축해제된 확장 프로그램을 로드합니다를 눌러 압축 푼 폴더를 골라요.
  4. 크롬에 내 구글 계정으로 로그인돼 있고 동기화가 켜져 있으면, GitHub 토큰과 GM 패널 버튼 설정이 자동으로 들어와요.
  5. 저널을 GM으로 한 번 열면 상점 알림 연결도 자동으로 돼요.

PC방에서

  • 컴퓨터가 바뀌어도 이 페이지에서 내려받아 위 순서대로 깔면 돼요. 폴더 위치가 달라도 같은 확장으로 알아봐서 계정에 저장된 설정을 그대로 가져와요.
  • 다 쓰고 나면 크롬에서 구글 계정 로그아웃을 꼭 해 주세요. 로그인된 채로 두면 다음 사람이 토큰을 쓸 수 있어요.
  • PC방에 따라 개발자 모드가 막혀 있으면 깔 수 없어요.

새 버전이 나오면 이 페이지의 파일이 바뀌어요.
